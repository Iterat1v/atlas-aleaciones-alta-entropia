# Atlas de Aleaciones de Alta Entropía

Dashboard interactivo del Dataset 3 (1,527 registros, 672 fórmulas): propiedades mecánicas, estructura cristalina, proceso y temperatura. Estilo liquid glass, sin servidor: `index.html` + `datos.js`.

Fuente de los datos: Borg et al. (2020), *Scientific Data* 7, 430.
