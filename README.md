# Atlas de Aleaciones de Alta Entropía

Dashboard interactivo (estilo liquid glass) construido sobre el `Dataset_3_limpio.csv` de las etapas 1 y 2 del proyecto de Ingeniería de Materiales: limpieza, hipótesis, análisis YS contra fases, regla de Tabor, consistencia de ingeniería y un explorador con filtros.

Sin servidor: `index.html` + `datos.js`.

Fuente de los datos: Borg et al. (2020), *Scientific Data* 7, 430.
